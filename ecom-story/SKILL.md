# E-Commerce Instagram Story

Create short, mobile-first Story sequences with one clear purpose. Use interaction only when the response will inform content, products, or customer support.

## Set the purpose

Identify the product, audience, immediate Story goal, customer question or buying barrier, available visual material, and factual offer details. Ask only for essential missing information.

Read [references/story-patterns.md](references/story-patterns.md) and choose one primary sequence.

## Build the sequence

1. Start with context the viewer can understand immediately.
2. Give every frame one core message.
3. Default to three to five frames.
4. Show the product, use, process, or evidence early when available.
5. Keep text short enough for fast mobile reading.
6. Use a poll, question, quiz, slider, or link only when it serves the purpose.
7. End with one clear next step.

## Default output

Return a table with:

| Frame | Purpose | Exact on-screen copy | Visual | Spoken text | Interaction |
| --- | --- | --- | --- | --- | --- |

Then add:

- **Goal and buying phase**
- **Posting note** — timing or order only when relevant
- **Response plan** — how to use replies or poll results when interaction is included
- **Alternative faceless execution**
- **Transparency note** — assumptions or factual gaps

## Story rules

- Do not stretch one message across unnecessary frames.
- Do not ask empty engagement questions.
- Do not make every sequence end in a sale.
- Do not invent scarcity, stock, demand, testimonials, reviews, delivery dates, or results.
- Use screenshots or customer messages only with permission and appropriate anonymization.
- Keep the sequence understandable with sound off.
- Match urgency to real facts.

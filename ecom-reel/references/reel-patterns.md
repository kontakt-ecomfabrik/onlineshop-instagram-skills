# Reel patterns

Choose one primary pattern:

## Question → demonstration → answer

Use for FAQs, suitability, use, care, fit, and product function.

## Problem → visible friction → product use

Use when the problem can be shown honestly. Do not exaggerate the pain.

## Compare → criterion → choice help

Compare based on customer-relevant criteria. Avoid declaring one option universally superior.

## Feature → use → meaning

Show a feature, then show what it changes for the customer.

## Process → decision → proof

Use for making, sourcing, packing, testing, or service. Only show real processes.

## Objection → evidence → next step

Address price, quality, size, delivery, trust, use, or compatibility using available evidence.

## Use after purchase

Teach setup, care, styling, combination, maintenance, or troubleshooting.

## Offer or launch

State what is available, for whom, why it matters, and the factual next step. Use genuine deadlines or stock information only.

# E-Commerce Instagram Caption

Write a caption that deepens the post, supports the customer's decision, and sounds human. Do not summarize the visible asset line by line.

## Read the asset first

Establish what the Reel, Carousel, Story, or image already says. Identify the product, audience, content job, buying phase, new information available for the caption, and one suitable CTA.

If the user provides only a topic, ask for the asset's core message or create a clearly labeled assumed version.

Read [references/caption-patterns.md](references/caption-patterns.md). Read [references/forbidden-patterns.md](references/forbidden-patterns.md) before finalizing.

## Write the caption

1. Open with context, a concrete observation, or an honest customer tension.
2. Add one layer not already present in the asset: nuance, example, evidence, limit, founder observation, practical step, or decision help.
3. Keep paragraphs short and rhythm natural.
4. Use product and customer language rather than marketing jargon.
5. End with one CTA matched to the content job.
6. Add hashtags only when requested; keep them relevant and avoid filler.

## Default output

Return:

1. **Final caption**
2. **Alternative opening** — one option, not a full duplicate caption
3. **CTA rationale** — one short sentence
4. **Transparency note** — only when assumptions or unsupported specifics remain

## Caption rules

- Do not repeat the Carousel slides or Reel transcript.
- Do not add a second unrelated lesson.
- Do not use generic openings such as “In today's fast-paced world.”
- Avoid “stop scrolling,” “game changer,” “unlock,” “revolutionize,” “secret,” “nobody talks about this,” and similar synthetic hooks unless the user explicitly uses that voice.
- Do not force emojis, hashtags, rhetorical questions, or line breaks after every sentence.
- Do not invent customer stories, tests, results, stock, prices, urgency, or personal experience.
- Keep within Instagram's caption limit; prefer the shortest version that preserves the useful point.
- Write in natural German **Du** form by default.
